# Proposer une amélioration

Merci de vouloir améliorer Temperator ! Les contributions se font **uniquement ici, sur GitHub**.

## Signaler un problème ou proposer une idée

Ouvre une [issue](https://github.com/Buntasam/Temperator/issues) et indique ce qui se passe, et ce que tu attendais.

Ajoute le **rapport de diagnostic** : en mode complet, *Réglages → Général → Rapport de diagnostic → Copier*, puis colle-le
dans l'issue. Il contient la version, Windows, le matériel détecté, les valeurs lues, les réglages et les dernières erreurs.
(En mode simple : clic droit → *Mode complet*, puis la même chose.)

## Proposer du code

1. Fais un fork du dépôt sur GitHub et crée une branche.
2. Fais tes modifications. Pour compiler et tester, suis la partie *Pour les développeurs* du [README](README.md).
3. Ouvre une pull request vers `main` en expliquant ce qui change et pourquoi.

Ton fork sert uniquement à proposer ta pull request : merci de ne pas publier ni distribuer ta version ailleurs.
